## 研究と開発

### Interactive EHR

診療タスクに応じて、電子カルテから必要な情報を取得し、専用の画面に表示する研究用プロトタイプです。

LLMが生成した画面構成をグラフとして表現し、SQLによるデータ取得と画面表示につなげています。利用者の要求、SQL、取得結果、表示の対応を確認する評価の仕組みも開発しています。

主な技術は Python、Gemini、Streamlit、Pydantic、SQL、SQLGlot です。

[コード](https://github.com/50m-regent/interactive-ehr) · [研究紹介](https://github.com/50m-regent/50m-regent/blob/master/projects/interactive-ehr.md)

### grun

店舗の伝票、レシピ、在庫を管理するWebアプリです。個人で制作し、iPadでの操作や暗い店内での利用を想定した画面を設計・実装しています。

伝票の作成・会計・訂正・取消と、レシピに応じた在庫管理をつなげています。主な技術は React、TypeScript、Material UI、FastAPI、SQLAlchemy です。

[ダミーデータを使った画面と制作の説明](https://github.com/50m-regent/50m-regent/blob/master/projects/grun.md)

どちらも個人制作です。Interactive EHRは研究用プロトタイプで、臨床での安全性や作業効率の改善は今後の評価課題です。
